# Jenny Mod — Install & Troubleshooting Guide

Jenny Mod is a Minecraft mod with mature themes, for adult players (18+) only. This page covers how to install it on Java Edition with Forge, how to install the Bedrock packs, and where to find fixes when it does not load.

## Java Edition (Forge)

Works with Minecraft 1.12.2 and Forge 1.12.2. Available versions include Forge builds v1.2 through v1.9.0, plus the Fapcraft variant (v1.0 and v1.1).

1. Install Minecraft: Java Edition and launch version 1.12.2 once, so the game files are created.
2. Install Forge 1.12.2 (Install client) from the official Forge site.
3. Launch the Forge profile once to confirm it reaches the main menu, then close the game.
4. Open the mods folder: Windows `%appdata%\.minecraft\mods`, macOS `~/Library/Application Support/minecraft/mods`, Linux `~/.minecraft/mods`. Create the `mods` folder if it is missing.
5. Copy the Jenny Mod `.jar` straight into `mods`. Do not unzip it and do not put it in a subfolder.
6. Launch the Forge profile, open Mods, and confirm Jenny Mod is listed. Test in a new world before opening an existing save.

Full step-by-step install guide: https://jennymodmincraft.com/installation/

## Bedrock / Android

Bedrock uses `.mcpack` and `.mcaddon` files instead of Forge. Open the pack with Minecraft, wait for the import, then activate the resource pack and the behavior pack in the world settings. A Java `.jar` will not work in Bedrock.

## If it does not load

- Not in the Mods list: you probably launched the vanilla profile instead of Forge, or the `.jar` is in a subfolder of `mods` instead of directly inside it.
- Version mismatch: the mod, Minecraft and Forge must all be the same version. A 1.12.2 mod does not load in 1.20 or 1.21.
- Fabric: this mod needs Forge, not Fabric.

Step-by-step fixes for freezes, crashes, missing dependencies, spawn eggs, textures and phone installs: https://jennymodmincraft.com/troubleshooting/

## Where to get it

Jenny Mod is not on CurseForge or Modrinth — both ban this kind of content, and CurseForge removed it. Use a maintained guide and a current download source, and check the file version before installing.
