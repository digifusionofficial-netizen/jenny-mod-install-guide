Before you install — three checks that save an hour

Most failed installs are decided before the file is even copied. Run these three checks first and you will skip the most common errors entirely.

1 · Which edition do you have?

Java Edition (PC / Mac / Linux) uses Forge and .jar files. Bedrock (Windows app, Android, iPhone, console) uses .mcpack and .mcaddon files. A Java .jar does not work in Bedrock, and a Bedrock pack does not work in Java. Pick the file for your edition.

2 · Which game version?

The documented Java setup is Minecraft 1.12.2 with Forge 1.12.2. Check the version your file was built for and match all three — mod, Minecraft and Forge — to it. If your file says a different version, use that version instead.

3 · Is the file real?

Check the real file extension before installing. A .jar must stay a .jar — do not extract it. A .mcpack / .mcaddon must be opened with Minecraft, not unzipped by hand. If a download arrives as a ZIP, look inside before assuming it is the mod.

4 · One build per profile

Pick one Jenny Mod build per profile. Two versions of the same mod in one mods folder will conflict. The same applies to Fapcraft — it is a variant, not an add-on to stack on top of Jenny Mod.

Java Edition install — Forge, step by step

Six steps, about ten minutes. The order matters — Forge first, mod second, and a test world before your main save.

  1. Run Minecraft 1.12.2 once. In the launcher, go to Installations → New Installation → choose release 1.12.2 → save → launch it once to the main menu → close it. This lets Minecraft prepare the game files for that version.
  2. Install Forge. Download the Forge installer for 1.12.2 from the official Forge site (files.minecraftforge.net), run it, choose Install client, confirm the Minecraft directory, and click OK.
  3. Launch with Forge once. In the launcher, pick the Forge installation and click Play. If it reaches the main menu, Forge works. Close Minecraft again — at this stage you have installed the loader, not the mod.
  4. Find the mods folder. Windows: press Windows + R, type %appdata%\.minecraft, and open the mods folder (create it if it does not exist). macOS: ~/Library/Application Support/minecraft/mods. Linux: ~/.minecraft/mods.
  5. Add the .jar. Copy the Jenny Mod .jar directly into the mods folder. Do not extract it — Forge reads .jar files directly. Do not put it in a subfolder inside mods.
  6. Launch and check. Open the launcher, select the Forge installation, click Play, then open the Mods menu and look for Jenny Mod. If it is listed, Forge recognised it. Then create a test world and check it works there before opening your main save.

If Forge itself will not launch

Re-run the Forge installer and confirm it pointed at the same Minecraft folder your launcher uses. A second Minecraft install (or a moved folder) is the usual cause — the installer and the launcher must agree on the directory.

If the game loads but Jenny is missing

Check the Mods menu first, not the world. If Jenny is not listed there, the file never loaded — see the fixes section below for “not in the Mods list”.

Bedrock & Android — packs, not Forge

Bedrock has no Forge and no mods folder. Everything is a pack you import and then activate in a world.

  1. Get the right pack. Use jennymodminecraft.mcpack as the main pack, plus jenny-texture.mcpack for textures and jenny-dweller.mcaddon if you want the dweller add-on. Do not use a Java .jar here — Bedrock cannot install it.
  2. Import it. Open the .mcpack or .mcaddon file with Minecraft and wait for the import to finish. On Android, tap the file and choose Minecraft; on Windows, double-click it.
  3. Activate both packs. In a world, go to Resource Packs and Behavior Packs and activate each pack the add-on needs. Importing alone is not enough — a pack that is imported but not activated does nothing.
  4. Test in a new world. Create a fresh world with the packs active and check the content appears before you enable the packs in an existing world.
On phones: the same steps apply on Android and iPhone — open the pack with the Minecraft app, then activate it in the world. If the file will not open with Minecraft, check the extension: a .jar will never open in the Bedrock app.

Phone APKs — read this before installing one

Five phone builds (1.0–1.4) exist in the download set. They are a separate mobile route — not the same as the Java mod or the Bedrock packs.

What they are: “Jenny Mod in Minecraft” phone builds, versions 1.0 through 1.4. Version 1.0 ships as a .xapk; 1.1–1.4 ship as .apk files.

Be careful: the site’s own APK row marks these “Not verified”, and an .apk does not automatically add mod content to Minecraft. Check the file and its source before installing anything on your phone, and avoid unknown installers asking for unrelated permissions.

If you want the mod on your phone, the safer route is Bedrock: install the .mcpack / .mcaddon packs in the Minecraft app using the steps above, instead of sideloading an APK.

FAQ — the questions everyone asks

Does Jenny Mod work with Fabric?

No. This mod needs Forge, not Fabric. If you installed Fabric, install Forge for the same Minecraft version and use the Forge profile instead.

Which Minecraft version do I need?

1.12.2 for every Java build on this page, with Forge 1.12.2. If your file says a different version, use that version instead — the file, the game and Forge must all match.

Can I use it on Bedrock / my phone?

Yes — with the packs, not the .jar. Import the .mcpack / .mcaddon files in the Minecraft app and activate them in a world. A Java .jar will not work in Bedrock.

Why isn’t it on CurseForge or Modrinth?

Both ban this kind of content. CurseForge removed Jenny Mod for adult-content policy violations, and Modrinth’s rules ban promoting sexually explicit material. That is why so many old guides point at dead links — use a maintained guide and a current download source.

Do I need Fapcraft as well?

No — pick one. Fapcraft is a variant, not an add-on. Install Jenny Mod or Fapcraft in a profile, not both at once.

Is the phone APK safe?

Check before installing. The site’s own APK row marks the phone builds “Not verified”, and an .apk does not automatically add mod content. The safer phone route is the Bedrock packs in the Minecraft app.

I installed it and nothing changed. What now?

Open the Mods menu first. If Jenny Mod is not listed, the file never loaded — go back to the first three rows of the fixes table above. If it is listed, test in a new world before touching your main save.
